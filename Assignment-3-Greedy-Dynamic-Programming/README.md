# Greedy and Dynamic Programming Solutions

This repository contains Java solutions for two algorithmic problems.

## Problem 1: Scholarship Distribution
- Approach: Greedy
- Time Complexity: O(n log n)
- Space Complexity: O(1)

## Problem 2: Maximum Learning Points
- Approach: Dynamic Programming
- Time Complexity: O(n)
- Space Complexity: O(1)

## Project Structure

```
.
├── ScholarshipDistribution.java
├── MaximumLearningPoints.java
└── README.md
```

## Compilation

```bash
javac ScholarshipDistribution.java
javac MaximumLearningPoints.java
```

## Execution

```bash
java ScholarshipDistribution
java MaximumLearningPoints
```

Compatible with Java 8 and above.

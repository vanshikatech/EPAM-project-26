# 🏦 XYZ Bank - Diwali Coupon Generator

A simple JavaScript project developed as part of the Infosys Springboard JavaScript Case Study.

## 📌 Features

- Welcome message on mouse hover
- Hide instructions after registration
- Customer ID validation
- Generate Diwali coupon code
- Error handling for invalid and blank Customer IDs
- Modern and responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```
XYZ-Bank-Diwali-Coupon
│── index.html
│── style.css
│── script.js
└── README.md
```

## 🚀 How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html` or open it using Live Server in VS Code.

## 📸 Project Workflow

1. Hover over **Welcome Customer**.
2. Register to hide instructions.
3. Enter Customer ID.
4. Validate Customer.
5. Generate Coupon.
